## What now works together

The existing persistent session first discovers the advertised Crossref contract, explicitly learns the RCSB GraphQL endpoint, composes a scientific-publication lookup and retains its goal. GraphQL still needs its source declaration: this is not automatic discovery of every environmental interface. A newly advertised local OpenAPI source then contributes a real gzip operation, asynchronous monitor and result to the same graph. Discovery requires no write grant. Operator approval permits one exact submission; its actual artifact is checked separately. Revoking that grant blocks the identical retained action.

The same runtime then executes 24 measured adaptation/control phases through ordinary interfaces:

1. The controlled provider changes its operation identifier and wraps its result in a nested object. Refresh discovers the compatible release. The same saved goal executes on new input only after a new operator-approved request; it reaches the real artifact digest through existing typed projection and async execution.
2. The provider moves the write to a different target. The saved goal and its generated endpoint refuse the changed meaning with **zero transport requests**. Calling the separately discovered action also fails at the independent issuer.
3. Withdrawing the source advertisement removes the provider. The saved goal refuses its missing required anchor with **zero transport requests**.
4. Returning the compatible release restores the same goal. New parameters remain denied until separately approved; the new artifact then completes.
5. Three stopped workflows remain after refusals. Explicit resume attempts remain pending, expose no executable resume selector and make **zero transport requests**. There is no speculative replay or false claim that every denial proves non-execution.

The retained goal's inputs, output, intent, predicates, anchors, origins and risks are compared before/after. Usage counts and selected implementation may change; obligations do not. The host changes disposable software releases and grants; it never injects graph nodes or rewrites saved goals. The final session produces exactly three expected gzip artifacts and no publications.

## Minimal changes and the defects they address

**Historical dependency evidence.** A later failed attempt previously replaced the dashboard's dependency comparison with an observation containing only the goal. Changed or missing dependencies could consequently appear current. `ActivityLog.latestCompleted` now retrieves the last completed observation from the existing bounded history. Validity compares those dependencies while assurance still reports the latest attempt. Evidence references identify the actual completed observation. Missing/truncated history never becomes positive assurance. No planner, execution permission, persistence format or public tool is changed.

Two deterministic regressions fail on frozen `1d409a0` and pass after the correction. They use an unrelated weather/translation scenario, including restart, withdrawal and missing/truncated history. This is development generalization, not a sealed holdout. Seven views in the final compression session also satisfy the expected validity states.

**Exact operator approval.** The new checker found a distinct security gap in the experiment controller: native Actenon proofs bound all wire headers, but the operator's approved-request key omitted them. A separate baseline control changed `Accept` and actually started a disposable job. This failure is preserved. The controller now compares method, target, encoded body and the complete header map before proof issuance. The experiment explicitly approves the transport's known headers; it never derives approval from the agent's attempted request. Equivalent header ordering is allowed; changed/missing/extra headers, method, target and body refuse. Revocation still refuses the exact request.

Before this change, the pinned native Permit model, PDP and scope tests were re-examined. Grant scope matching covers action types; native proof minting binds exact parameters. An operator must constrain parameters before issuing their proof. This change corrects the trusted experiment controller, not Actenon's cryptography. Actenon source, native verifiers, effect reservation, replay store and resource-owned gate remain unchanged. There is no new mandatory dependency or authority setter in RightClick X.

**Experiment surface.** Optional controlled provider release profiles and one session extension reuse the current generic discovery/planning/async/adaptation path. These profiles are exposed development fixtures. They do not qualify as unfamiliar independent software, and no compression-, RCSB- or Crossref-specific branch was added to product code.

## Preserved failures and limits

All four integrated trials remain. Attempt 1 failed an incorrect assertion about the generated endpoint's error shape. Attempt 2 exposed misleading validity and a checker assumption that stopped workflows should be empty. Attempt 3 exposed the omitted-header approval key. Attempt 4 passes the stricter checker. Earlier fixture mistakes and final frozen-baseline failures are retained; the checker still enforces all original exact-action and zero-dispatch conditions.

Three stopped checkpoints conservatively consume retained recovery capacity. Generic HTTP refusal does not justify deleting them or declaring safe retry. A future, independently authenticated non-execution/reconciliation signal could support explicit cleanup; this increment does not invent it. Validity remains a bounded historical descriptor comparison, not proof that remote behavior or current authority is unchanged.

The resource-owned fixture covers its sole effect route and the existing protected-workflow probes cover direct HTTP, shell/socket aliases, framing, absent credentials and authority mounts. Other shells, credentials, generated endpoints, alternative tools and federated runtimes require their own demonstrably protected routes. No universal containment or execution-surface visibility is claimed. The earlier native short-allocation hard-memory containment failure remains **FAIL**.

The attempted review-tool discovery was unavailable; no independent-author review occurred. No fresh model participated in this combined adaptation session. Earlier actual-model reuse evidence remains valid at its own scope, but cannot be relabelled as this session's missing fresh-model act. Independent unfamiliar holdouts, cross-vendor evidence, complete challenge coverage, clean-machine Actenon provisioning, unfamiliar-developer installation and human/commercial validation remain open. Historical mixed/adverse strong-agent and saved-script economics remain unchanged. Commercial superiority is not established.
