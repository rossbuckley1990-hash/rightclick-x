## Current material issues

- The [completed Codex pilot](CODEX-DEVELOPMENT-RESULT.md) confirms fresh discovery reuse but no runtime/model-effort advantage. All 291 current regression tests pass; the result does not satisfy the commercial or holdout gates.
- The subsequent [32-session recheck](MODEL-RECHECK-RESULT.md) completes after separately reconciling a host-sleep interruption. D warm median is 17.2 s versus A 12.2 / B 10.4 / C 21.6. All arms return four correct feasible outputs; no qualifying economic advantage. The gap between D and resumed baselines prevents causal timing attribution. B/C recover correct values in the reversed-output phase while failing its refusal criterion; they are not wrong-value answers. Working publication and automatic compatible repair now occur through actual model calls, and the later [changed-operation checkpoint](CHANGED-ACTION.md) closes the reproduced local acknowledgement/planned-call gaps. This does not retrofit independent authority into the model pilot.
- [Compact disclosure](DISCLOSURE.md) reduces serialized default explanations 41.9% on one exposed retained target. Full detail and execution constraints remain available; initialization is shorter, but the tool list grows. The later model recheck above reports measured traffic but establishes no qualifying economic advantage. Consumers parsing the old default explanation shape must request `detail:"full"`. A slow repeated goal-publication test remained active after 3m18s and was stopped; that performance diagnostic remains unresolved.
- The [local CLI repair correction](CLI-REPAIR.md) and [structured probe correction](CLI-SAMPLE-COVERAGE.md) establish the real saved-goal lifecycle. [Inference continuity](CLI-MIGRATION.md) now resolves the two prior upgrade failures using matching fresh evidence, identical binary/invocation and unchanged saved anchors. All 19 exposed replay cases pass. Missing evidence, changed contracts and snapshots that already lost the old evidence remain refused. Portable knowledge uses format 2 and checks inference compatibility; old receivers reject it, and new receivers reject legacy envelopes or unknown inference profiles. Automatic cross-version bundle migration remains unestablished. These bounded compatibility checks are not universal semantic proof or independent execution authority.
- Caller acknowledgement can no longer clear known changed meaning, including planned execution and static composite preflight. Fresh operations have distinct identities and do not inherit exact capability approvals. The unprotected reset diagnostic still records writes through new identity, direct API and reset/re-discovery. Independent exact-action authority is therefore required outside local runtime bookkeeping; this remains a deployment gate. Same-title/type heuristic repair without contradictory observations also remains a hypothesis requiring outcome verification and exact authority.

- Four exposed ExifTool selector tasks remain refused. Generic dynamic option families require bounded disclosure, collision handling and revalidation; adding a provider-specific selector list would not satisfy the objective.
- The macOS sandbox deliberately denies home-directory file reads. Authorising a program path does not automatically make a home-directory executable or alias readable there. The Codex development runner exposed this mismatch and now stages only disposable executable aliases outside the private evidence tree. This harness correction is not a general solution for private installed software and does not relax the sandbox.
- [Structured CLI inputs](CLI-STRUCTURED-INPUT.md) now support inline JSON, files and stdin for run/compose, reject ambiguous/lossy input before runtime creation and return nonzero exit status for failed runs. The offline installed fixture produces five correct real-program outputs, reuses retained reflections and uninstalls. Its initial wrong file-role assumption is preserved. This closes that concrete input blocker, not unfamiliar-developer usability or economic validation.
- Retained state contains more graph/ledger data than a small saved script. Its additional cost must earn a measurable reliability or maintenance benefit. The deterministic runtime comparison did not establish one.
- The optional Actenon prototype uses audited source snapshots including unreleased components. A registry-only production stack, supported version matrix, ordinary operator credential custody and clean uninstall experience remain open.
- Independent-author validation is not replaced by a checker written by the implementation author. Separate Python and native cryptographic checks improve reproducibility while retaining that limitation.
