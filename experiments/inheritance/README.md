# Inheritance fixture guards

These helpers support a future, operator-controlled inheritance test. The unit
tests run as part of `npm test` and exercise phase-specific tool selection,
allowlisted local CLI discovery, goal-definition comparison, and receipt binding.

This is fixture code, not a production security boundary. It does not launch an
agent, sandbox a model process, enforce network isolation at the operating-system
level, establish a billing limit, or prove autonomous capability inheritance. The
helpers are not yet connected to an executable harness on this branch. Further
integration and independently validated execution isolation are required.
