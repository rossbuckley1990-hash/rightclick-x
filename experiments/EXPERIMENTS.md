# Live-internet experiments

Run with `node experiments/cloud.ts` (or `node experiments/cloud.ts E3 E7` for a subset). Every provider below is a real public service. RightClick X contains no code specific to any of them. All calls are read-only. Raw results: [`results/latest.json`](results/latest.json), console log: [`results/latest.log`](results/latest.log). Numbers below are from the run on 2026-10-16 (Node 24.16, one laptop, home network).

"Powers" = capabilities + typed links + 3-step typed chains. It measures how much *can* be wired together, not how much of it is useful; the planner's job is to find the useful part.

## What the live web taught the runtime

The first live runs failed in instructive ways. Each fix is general, not provider-specific:

- **Depth-limited GraphQL servers** reject full introspection (HTTP 413) → introspection retries at shallower type-reference depths, and truncated types are treated as unknown, never as strings.
- **Generic names** (`code` on field `country`, `id` on a `release`) → semantic types use context: `country(code)` is a `country`, `release.id` is an `id.release`.
- **Identifier soup at GitHub scale** (any `*_id` flowing into any other) → qualified identifiers; `ghsa_id` and `check_run_id` never mix.
- **Name-like ports** (`title`, `name`, `q`) accept specific string types (a `place` can be a Wikipedia title) but never prose fields (`body`, `description`).
- **Plans that ignore what the caller supplied** → ranking starts with how fully a plan uses the caller's inputs; a caller's identity values beat derived ones; transformed text always takes the latest version.
- **Kubernetes `name` parameters are identifiers**, not names: "name of the Namespace" in a parameter's description now types it `id.namespace`, so a country code can never be mistaken for a resource name.
- **Prose is not purpose**: Wikimedia's descriptions mention "rate limits", which made an HTML endpoint look like it covered "exchange rates" (and a weak check passed it). Intent coverage now comes from what a capability is (title, tags, the outputs it uses), not incidental description text.
- **The edge has budgets.** Cloudflare caps outbound requests per invocation; acquisition and healing probed every candidate ten ways and hit it. Directory candidates now carry their kind, and are learned with one targeted probe.
- **Enumerations are choices, not inputs.** An acquired MCP tool's `indicator` parameter (one of population, gdp, …) was being fed Wikipedia text, and that junk plan outranked the real one. Ports with declared enums are now filled only by the caller.
- **Shared egress IPs share rate limits.** Unauthenticated GitHub calls from Cloudflare hit a limit exhausted by other tenants; authenticated calls (an origin-pinned token in `RCX_AUTH`) are the fix.
- **Memory must not outlive its cause.** After the credential was added, A still remembered three rate-limit failures and pruned the GitHub route. Persisted state now records a fingerprint of each origin's credentials (never the credentials); when they change, that origin's past 401/403/429 failures are forgiven. Routes through a caller's `through` anchors are never pruned from the search.
- **Joins need different branches.** Binding each input in isolation fed DeepWiki the repository description instead of the issue body. Binding now fills the most constrained input first and prefers values from branches nobody has consumed, so a join draws each input from a different system; anchored steps may start parallel branches.
- **Upgrades must reach persisted graphs.** A's restored GitHub reflection predated the `owner/repo` type, so nothing produced it. State now records its semantics version and re-derives stale reflections on boot.
- **Ambiguous intent across 1,300 endpoints** → `through` anchors let an agent pin the capabilities it means; the planner wires the types between them.
